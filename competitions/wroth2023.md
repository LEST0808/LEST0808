## 📌 Competition Overview

**WRO Future Engineers Thailand 2023** is an autonomous robotics competition focused on vehicle control, obstacle avoidance, and navigation.

Our team developed an autonomous car-like robot capable of completing the competition tasks using **computer vision, ultrasonic sensors, and sensor fusion**.

---

- Documentation

- Robot circuit system

---

## 🤖 Robot

The robot used an **Arduino Uno**, motor driver, and sensor shield.

The system combined camera and ultrasonic sensor data for **obstacle detection and navigation**, while **PID control** was used to maintain stable steering.

The robot design was based off of a car, adopting the "Parallel Steering System". This steering system allow the robot to steer with high mobility, allowing the robot to be able to U-Turn without taking much space.

### Main Technologies

`Arduino` `Computer Vision` `PID Control` `Ultrasonic Sensors` `Sensor Fusion`
